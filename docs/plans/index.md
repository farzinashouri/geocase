  site via `exclude_docs` in `mkdocs.yml` and is read here on GitHub. A published page must
  not link to a plan with a relative path — `mkdocs build --strict` fails on it. Link to the
  file's GitHub URL instead. See
  [Plan 30](30-unpublish-internal-docs-and-surface-catalog.md).
