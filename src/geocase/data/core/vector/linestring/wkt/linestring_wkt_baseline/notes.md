# LineString WKT Baseline

## Purpose
Tests LineString geometry loading from plain WKT file.

## Data
- Geometry: `LINESTRING (10 50, 10.5 50.3, 11 50.1)`
- Attributes: none. The format has no attribute slot;
  `VectorCase.load()` synthesizes a single `name` = `linestring_wkt_baseline` row.
- Feature count: 1

## Validation
- Geometry type: `LineString`
- CRS: `EPSG:4326`, supplied by `case.yaml` — the format stores none
- Geometry equals `simple_valid_linestring` under `shapely.normalize`, which is how
  `tests/unit/test_cross_format_canonical.py` compares them. The comparison is
  winding-insensitive by necessity: the Shapefile specification mandates the
  opposite ring orientation from RFC 7946, and OGR rewrites winding on write.
  Orientation itself is asserted by `shapefile_ring_orientation`.
